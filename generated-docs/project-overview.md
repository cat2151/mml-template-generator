# Project Overview

## プロジェクト概要
- 最小限の入力（例：cdefgab、ドレミ）から、各種MMLコンパイラ向けのMMLコードを生成するツールです。
- MMLでの曲作りを始める際によくあるコンパイルエラーのハードルを低減し、すぐに音が出せるMMLを提供します。
- シンプルなウェブインターフェースを通じて、入力された音階から利用目的に合わせたMMLテンプレートを手軽に生成できます。

## 関数詳細説明
- **controller (controller.js)**: ユーザーインターフェースからのアクション（ボタンクリックなど）を検知し、MMLの生成プロセスを開始する中心的な関数です。ユーザー入力に応じたMMLの生成ロジック（`services.js`内の関数）を呼び出します。
- **function (controller.js)**: `controller.js`内で、特定のUIイベントハンドラとして使われる可能性のある匿名関数または内部関数です。ユーザーの操作に応じた特定の処理を実行します。
- **getMiddleText (services.js)**: 入力されたテキスト（cdefgabなど）から、MMLの本体部分に変換するための前処理を行う関数です。
- **sion (services.js)**: 特定のMMLコンパイラ「sion」向けにMMLをフォーマットするロジックを含む関数です。
- **sutoton (services.js)**: 特定のMMLコンパイラ「sutoton」向けにMMLをフォーマットするロジックを含む関数です。
- **auto (services.js)**: MMLの自動生成や、入力された音階情報から適切なMML要素を自動的に割り当てる処理を行う関数です。
- **generate (services.js)**: 選択されたMMLフォーマットに基づいて、最終的なMMLコード全体を生成するメイン関数です。ヘッダ、ボディ、フッタ部分を統合します。
- **genHead (services.js)**: 生成するMMLの冒頭部分（ヘッダ）を構成する関数です。MMLコンパイラによっては初期設定やメタ情報が含まれます。
- **gen1ch (services.js)**: 入力された音階情報から、MMLの一つのチャンネル（トラック）分のMMLコードを生成する関数です。
- **genTail (services.js)**: 生成するMMLの末尾部分（フッタ）を構成する関数です。MMLの終了コマンドや後処理が含まれる場合があります。
- **getABC (services.js)**: ユーザーが入力した音楽記号（例: 'c', 'd', 'e'）をMMLの表記に変換するための処理を行う関数です。
- **controller (services.js)**: `services.js`内にある、サービス層のロジックの一部として機能するコントローラ的な関数です。
- **function (services.js)**: `services.js`内で定義されている内部的な処理を行う匿名関数、または汎用的なユーティリティ関数の一部です。
- **service (services.js)**: サービス層の主要な機能、または特定のMML生成サービスを管理する関数です。
- **forEach (services.js)**: JavaScriptの標準的な配列操作メソッドで、MML生成処理の中でリストの要素を反復処理するために使用されます。
- **if (services.js)**: JavaScriptの条件分岐構文であり、MML生成ロジック内で特定の条件に基づいて異なる処理を実行するために使用されます。
- **bgm (services.js)**: BGM（バックグラウンドミュージック）として利用できるMMLを生成するための、またはその処理に関連する関数です。
